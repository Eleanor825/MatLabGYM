## M0 · 把实验环境跑起来

**状态：工程原型已完成，代码已合并 main。**

我们先让 Agent 在软件里完成一次完整的筛选过程：选一个配方，启动配液，等操作完成后测电导率，再根据结果选择下一个配方。不同环境共用一套操作和返回接口，评测程序也不必为每个场景单独写一遍。

实现上，我们把步骤顺序、设备占用、样品关系和实验预算写成明确规则。实验结果只有在对应操作完成后才会公开；重复请求不会重复做实验或多拿奖励。每次运行都保存记录，并通过重放检查状态、结果、奖励和成本是否一致。

**目前已验证的范围：**95 项测试、公开顺序／随机／根据已测结果选点的三种示例策略，以及多 Python 版本 CI 均已通过。电导率反馈覆盖配液和表征两步；完整六阶段产线也能模拟执行，但没有接入真实电芯容量、寿命等结果。

这一阶段的软件运行和检查目标已经达到。正式版本标签、发行包和版本说明仍在 TASK-004 中；真实科学效果由后续阶段验证。

相关资料：[统一接口](uniform_api.md)、[电解液场景](electrolyte_scenario.md)、[奖励设计](reward_design.md)。

## M1 · 让环境符合真实实验

**状态：准备中。接口清单已经整理，平台确认和真实数据接入尚未完成。**

现在的关键是确认软件里的规则是否符合实验室实际情况。例如，注液前是否必须表征、哪些步骤允许停止、停止后的样品还能不能使用，以及结果里的单位和样品编号如何对应。

我们已经整理了六阶段操作清单、9 项待确认决策和20个验收场景。接下来与平台、工艺和数据负责人一起，用实际材料逐项核对：

- 一条成功任务记录，确认从配方到结果的步骤和样品关系。
- 一条失败或中止记录，确认样品处置、重试和恢复方式。
- 一份真实测量数据及接口样例，确认来源、单位、质量和允许查询的范围。

**完成标准：**首个场景所需规则有 SOP、接口或日志依据，数据能追溯到原始测量；不能确认的范围明确排除。导入一份 CSV 并不自动证明数据可靠，也不能用电导率达标代替电芯性能达标。

相关资料：[操作清单](electrolyte_operation_inventory.md)、[接口验收清单](electrolyte_interface_acceptance.md)。任务见 TODO 的 TASK-006–011、TASK-013。

## M2 · 验证 Agent 是否真的有用

**状态：待开展，依赖可用的真实数据和独立评测。**

这一阶段回答一个问题：在同样的实验次数和条件下，Agent 能否更快找到满足目标的配方？我们会比较随机选择、固定顺序和利用测量结果的策略，并分别提供真实反馈、不提供反馈或打乱反馈，检查收益是否确实来自实验信息。

评测前会固定任务、数据划分和预算，并把尚未测量的结果与评分程序隔离，避免 Agent 提前看到答案。结果分别报告目标达成率、找到的最佳性能和用了多少次有效实验；奖励分数单独记录。若研究训练效果，还要记录训练过程，并在未参与训练的数据上验证。

**完成标准：**实验可复现，结果没有数据泄漏，失败任务也计入统计，并用足够的独立任务和重复实验说明效果及不确定性。只给同一条固定策略换一套奖励公式，不算能力提升。

任务见 TODO 的 TASK-012、TASK-014、TASK-015。

<a id="m3"></a>

## M3 · 接上实验室，先观察和核对

**状态：待开展，依赖平台接口、权限和状态定义。具备条件后可与 M2 并行。**

先让系统读取实验室的任务、样品和测量结果，把软件理解的状态与现场记录逐项对上。这个阶段不让 Agent 直接触发设备动作，而是检查它准备发出的请求是否正确、收到的反馈是否被正确理解。

我们会重点检查断连、丢失响应、重复请求、服务重启和部分失败。系统必须知道什么时候可以重试、什么时候需要先查询实际状态，以及哪些样品要暂时隔离，避免同一个实验被重复执行或费用被重复记录。

**完成标准：**真实任务、样品和报告可以互相追溯，正常与故障场景都有对照记录，平台负责人确认状态和恢复行为符合实际。软件中的“时间到了”不能代替真实设备的完成通知。

任务见 TODO 的 TASK-016–018、TASK-022。

<a id="m4"></a>

## M4 · 做小规模真实实验，再扩展

**状态：后续阶段，依赖平台验收和明确的操作责任。**

在确认的设备、配方和操作范围内，开展少量真实试验，验证从方案到执行、结果和费用记录是否一致。试运行需要明确异常时谁接管、如何停止设备、怎样处理样品，并留下实际结果。

首个场景验证后，再决定是否扩展到完整电芯性能任务、其他材料体系或多 Agent 调度。每次扩展都要重新确认目标、数据和操作约束，并与已有方法比较，不能直接沿用电导率场景的验证结论。

**完成标准：**正常与异常路径通过现场验收，科学结果有独立质量判据，实际耗时和费用可以核对。对外提出效果结论时，还需满足 M2 的评测要求。

任务见 TODO 的 TASK-019–021。

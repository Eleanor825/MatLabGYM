## M0：统一接口与可运行电导率闭环

**目标：** 让 agent 使用同一套动作、观测和结果契约，运行“选择配方 → 配液 → 表征 → 根据已观测结果再次选择”的有限预算任务。

- **当前交付：本地已实现。** [ScientificEnv](../src/matlabgym/api.py) 统一 reset、step、observe、public_snapshot、action_specs、trace、evaluate 和 episode_outcome；公共 info 包含结果、奖励分解、来源和成本单位。[ElectrolyteEnv](../src/matlabgym/domains/electrolyte_screening.py) 将测量绑定到配液与表征完成后发布，提供支持域、测量预算及独立指标。
- **策略与证据：本地已实现。** 公开顺序、独立随机种子和基于本 episode 已观测反馈的最近邻贪心基线；[CLI](../examples/run_electrolyte_screening.py) 保存 manifest、metrics、trace 及回放结果。本地 95 tests 和 Ruff 检查通过；同 seed reset 已通过 reset 序号隔离身份，strict replay 可还原序号并拒绝旧 episode 输入；CSV 非整数温度及非法 uncertainty 被拒绝。发布版本、CI 结果和平台报告仍待补齐。
- **依赖：** 冻结当前接口与 trace 版本，确认示例、序列化和失败行为一致。模拟默认耗时和容量保留明确来源，不等待真实参数即可开展软件验证。
- **退出条件：** 从干净环境安装后执行统一接口测试、三策略示例及 trace 验证成功；验证已修复的同 seed reset 身份隔离，并记录跨 worker 命名空间边界；将代码、测试命令、配置和产物绑定到可审查的 PR/提交，CI 通过后按发布流程交付。以上发布退出条件尚未全部完成。

**边界：** 电导率闭环只有 S1 配液与 S2 表征。已有六阶段产线模拟覆盖 S1–S6 的执行顺序，但最终 cell_test_report 仍是元数据产物，未接入真实电池测试曲线或性能报告。S2 电导率达到阈值不表示 S6 电池性能达标。后续两类任务应保持独立 task ID、目标和验收标准。

## M1：九项平台决策与真实数据

**目标：** 将模板假设转换为有版本、可追溯的数据和平台契约。

- **交付：** DEC-01–09 全部签认或记录适用范围及未关闭原因；真实配方/参数/结果 schema、单位、支持域、QC 规则、协议注册表；授权可用的原始测量与冻结 replay 数据版本；样品谱系、真实 ID 映射、停止后隔离与恢复规则；首份真实测试报告的接入样例。
- **依赖：** 平台、工艺、数据负责人提供 API/SOP、脱敏请求响应、仪器校准和数据来源。真实数据导入不自动构成有效科学 oracle。
- **退出条件：** 对关键 AC 提供逐项证据和确认记录；导入器拒绝单位不一致、域外、非有限和不符合 QC 的记录；复测与缺失值处理有明确规则；支持域之外不以插值结果冒充真实测量；S1–S2 与 S1–S6 的任务边界被明确签认。真实数据版本能够复核来源、许可、质量筛选和结果报告链接。

## M2：独立科学 benchmark 与反馈消融

**目标：** 在冻结数据和独立评价条件下检验策略是否因有效反馈而改善选择。

- **交付：** 按配方、实验批次等泄漏风险划分的训练/开发/测试集；独立 evaluator 与隐藏结果的进程/文件隔离；固定 trial 分母、种子、预算及版本；公开顺序、随机和自适应基线；真实反馈、无反馈、扰乱反馈等预注册消融；成功率、best-found、simple regret、有效测量数与成本/时间的独立报告及不确定性分析。
- **依赖：** M1 冻结的数据支持域、QC 和科学有效性判据；M0 可回放接口；隐藏结果与评价接口对策略不可读。需说明结果仅适用于有限 replay 支持域。
- **退出条件：** 可从冻结版本复现实验；没有训练/测试或 evaluator 泄漏；预算与失败分母一致；消融有足够任务/独立重复支撑结论；独立指标与 reward return 分开报告。若声称“学习”，必须另有训练过程、参数更新及留出集评估；单次修改 reward 配置重算固定策略得分不是学习证据。

奖励边界和成本来源见 [reward 设计](reward_design.md)。最近邻贪心只是基线，不预设它优于随机，也不将 synthetic fixture 排名作为科学 benchmark 结论。

## M3：只读/影子平台对接与故障恢复

**目标：** 在不由 agent 触发真实设备动作的条件下验证平台状态、身份、结果与恢复语义。

- **交付：** 只读查询 adapter 与影子请求对照；真实 job/device/sample/report ID 和 episode 命名空间；持久化幂等记录；受理、物理启动、物理完成和质量有效的独立证据；断连、丢响应、重复/乱序回调、超时、部分失败、重启和对账故障集。
- **依赖：** M1 DEC-02/03/05/06/07/09 与只读接口权限；M0 序列化/版本契约。可在 M2 科学评估之外并行开展已具备依赖的工程工作。
- **退出条件：** AC-08/09/12–20 适用项有影子或故障测试报告；未知执行状态不触发自动重复执行；重复事件不重复扣费/产生奖励；停止或部分失败样品保持隔离，待明确放行；超时后仍可追踪真实任务。模拟 advance_time 不作为物理完成证据。

## M4：受控实机与后续扩域

**目标：** 在已确认的 SOP、操作范围和设备控制责任下开展有限真实试验，再决定是否扩展。

- **交付：** 明确人员责任、受控动作范围和实验批次的试运行方案；设备联锁与急停、人工接管、样品处置和恢复记录；完整真实执行与质量报告；实际耗时/成本标定。后续可选工作包括六阶段科学目标、其他材料域和多 agent 资源调度。
- **依赖：** M1 工艺与数据契约、M3 故障恢复和平台验收通过；实机动作由实际责任方确认。若对外提出科学性能结论，还需满足 M2 的独立评估条件。
- **退出条件：** 授权试验范围内每次动作可追溯到真实设备/样品和报告，正常及异常路径经现场验收；科学达标有独立 QC/判据支撑；费用可对账；遗留风险与扩展前置条件有记录。扩域和多 agent 应分别提出新 task contract、资源竞争测试和证据要求，不自动继承电导率任务的验证结论。
